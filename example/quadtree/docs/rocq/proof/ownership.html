The definition fields takes an integer object identifier o and a list of values vs and produces an Iris proposition asserting ownership of each field of ObjId o: the field at each list index i contains the corresponding value v. These assertions are combined using separating conjunction, so their ownership resources must be held separately. The definition assumes a cjrGS(Σ) instance; the input does not give the precise semantics of field ownership or assert anything about fields outside the list.
