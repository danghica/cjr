CJR · QUADTREE

Benchmark report

Report index

Three implementations: CJR extracted code, an independent native quadtree with the same fixed-domain subdivision policy, and a flat collection with hash-indexed membership and range scanning. The native baseline stores children in an ArrayList; extracted code stores four child fields, so the measured comparison includes layout costs. Uniform points span the depth-30 domain; clustered points occupy a 256-square; shared-prefix points fill a 128-wide grid near the origin.

Two warmup batches, independent calibration toward 20 ms, seven trials in each of three fresh processes. Implementation order rotates by trial and process. Construction and query repetition limits bound allocation; capped batches may take less than 20 ms. Complete results are checked against the flat oracle outside timing; checked checksums are consumed inside each batch. Construction, hits and misses report ns per point; range workloads report ns per query. Allocation and GC costs are included.
